# Smart Kettle Simulator

An interactive appliance model built with HTML, CSS, and JavaScript. Choose a target temperature, watch the kettle heat, and use **Pause & Keep Warm** to maintain the temperature reached so far.

## Run it

Open [index.html](./index.html) in a browser. No installation is needed.

## Features

- Select 50°C, 80°C, 90°C, or 100°C.
- Watch the displayed temperature and heating progress update.
- Automatically switch to **Keeping Warm** at the selected target.
- Pause heating at any time and maintain the current temperature.
- Cancel and return the kettle to **Idle**.

See [model-notes.md](./model-notes.md) for the states, variables, and transitions represented in the simulation.
